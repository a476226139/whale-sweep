# 海面 · 扫雷

9×9 的扫雷，一个 HTML 文件，双击就能玩，不用装任何东西。

## 怎么玩

- 左键/点按：挖开
- 右键/手机长按：插一个泡泡（标记）
- **点已经翻开的格子**：把周围八格一起掀开（不看雷，踩中就翻肚皮）
- 第一次点永远安全

## 私货

- 雷叫「渔网」，踩中会「（扑腾）被捞走了」
- 旗子是泡泡
- 挖完海面会静下来

## 声音

- 点格子有水滴声，插泡泡有气泡声，踩雷会闷一下，赢了有三声轻铃
- 背景音乐是现场合成的：慢和弦垫底，零星拨弦，带一点混响
- 顶栏那个 ♪ 可以关掉音乐

## 在线玩

用 GitHub Pages 就行：仓库 Settings → Pages → Source 选 `main` / `root`，等一分钟。

## 文件

- `index.html` —— 全部代码，样式、脚本、声音都在里面
