# 海面 · 扫雷

一个 HTML 文件的扫雷，双击就能玩，不用装任何东西。

## 怎么玩

- 左键/点按：挖开
- 右键/手机长按：泡泡 → 问号 → 空
- **点已经翻开的格子**：把周围八格一起掀开（不看雷，踩中就翻肚皮）
- 第一次点永远安全

## 难度

初 9×9 · 10 网 ／ 中 16×16 · 40 网 ／ 高 30×16 · 99 网，每档单独记最佳成绩。

## 私货

- 雷叫「渔网」，踩中会「（扑腾）被捞走了」
- 旗子是泡泡
- 画面是清透浅海：斜射光柱、往上冒的气泡、沙色格子、玻璃质感面板
- 音效按列定音，挖格子像弹琴
- 翻出数字时会游过几条小鱼

## 声音

- 点格子有水滴声，插泡泡有气泡声，踩雷会闷一下，赢了有三声轻铃
- 背景音乐现场合成：慢和弦垫底，零星拨弦，带混响
- 顶栏那个 ♪ 可以关掉音乐

## 无猜与复盘

- 首次点击时用求解器验算棋盘，只留「不用猜也能走完」的那种
- 踩雷时告诉你那一步粗估有几成是网

## 在线玩

用 GitHub Pages 就行：仓库 Settings → Pages → Source 选 `main` / `root`，等一分钟。
